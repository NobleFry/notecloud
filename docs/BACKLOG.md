## 8. 已知限制（不打算改 / 需要产品决策）

- **不做字符级实时协同编辑**（OT/CRDT）。协作靠乐观锁 + 冲突提示。
- **任务没有 per-task 可见性**（工作区内全可见），与笔记不一致。
- **笔记正文上限 2MB**，纯文本 Markdown。
- **笔记本最多 5 层**。
- **重复任务**不做完整 RRULE 日历展开。
- **MariaDB 不兼容**：`ngram` 解析器与部分 JSON 行为不同，生产必须 MySQL 8。
- **单实例假设**：WebSocket 连接表与定时任务都在进程内。
